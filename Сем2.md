### gpss world

У gpss блочная структура. Два вида блоков:
1. команды
2. операторы - обращение к подпрограмме, которая что-то делает

данная система позволяет моделировать СМО - системы массового обслуживания.

#### СМО

**СМО** - система по которой движутся динамически элементы (транзакты/заявки) - входят в систему, встают в очередь, обслуживаются, затем выходят.

Обслуживающее устройство - обслуживает транзакты

Классификация СМО
- по **числу каналов обслуживания** (одноканальные многоканальные)
- по **количеству фаз-обслуживаний** (однофазные и многофазные)
- по **дисциплине выхода из очереди** (первый пришел - первый обслужился; первый пришел - последний обслужился)
- по **приоритету обслуживания** (с приоритетом; без приоритета)

Общая запись формата блока
	<имя>Операция операнды; комментарии
	
###### Оператор входа транзактов в систему
```
	GENERATE A,[B],[C],[D],[E]
```
[] - может быть упущен, задан по умолчанию
1. A - середина интервала прихода транзактов в систему
2. B - по умолч 0, время которое определяет границу интервала
**Пример** - покупатели приходят в магазин через 5 +-3 минуты
```
	GENERATE 5, 3
```
1. C - смещение интервала, по умолч 0. 
**Пример** - в парикмахерскую приходят клиенты через 30 +-10 минут, первого клиента запускают через 15 минут после открытия
```
	GENERATE 30,10,15
```
1. D - одновременный приход нескольких транзактов, по умолч 1
2. E - приоритет, по умолч 0. Чем выше приоритет тем число больше
**Пример** - в парикмахерскую через 300 +-100 минут приходят ветераны боевых действий, которых обслуживают вне очереди
```
	GENERATE 300,100,,,1
```

###### Оператор выхода транзактов из системы
```
	TERMINATE [A]
```
А - счетчик завершения работы системы, по умолч 0
```
	TERMINATE 0
```
Таймер сегмент
```
	***
	GENERATE 600
	TERMINATE 1
	START 1
```
Условие остановки(?)
```
	TERMINATE 1
	START 10
```

###### Операторы занятия и освобождения очереди:
```
	QUEUE A,[B] 
	DEPART A,[B]
```
1. А - имя очереди (Och_prod например)
2. B - сколько транзактов одновременно входит в очередь (по умолч 1)
 **Пример** - покупатель занимает очередь с именем Och_prod

###### Операторы занятия и освобождения устройства
```
	SEIZE A 
	RELEASE A
```
A - имя устройства (Prodavec например)

###### Операторы обслуживания устройств
```
	ADVANCE A,[B]
```
1. A - середина интервала времени обслуживания
2. B - определяет границы интервала

**Пример** - продавец обслуживает одного покупателя в течение 4 +-2 минуты

---

**Задача** 
Покупатели приходят в магазин через 4 +-2 минуты, 1 продавец, и он обслуживает за 5 +-3 минуты. Магазин работает 10 часов 

Приходит в магазин
Встает в очередь
Занимает продавца
Выходит из очереди (освобождает очередь)
Обслуживается
Покидает продавца
Выходит из магазина

```
GENERATE 4,2
QUEUE Och_prod
SEIZE Prodavec
DEPART Och_prod
ADVANCE 5,3
RELEASE Prodavec
TERMINATE 0
***
GENERATE 600
```
