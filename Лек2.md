### Метод статистических испытаний Монте-Карло
Группа численных методов, в кот сложные математ задачи решаются с помощью **многократной генерации случ чисел** и проведения статисических экспериментов
Для выполнения проводят серию испытаний

Пример
требуется определить площадь фигуры, алгоритм:
![[Pasted image 20260925120413.png|200]]
m - кол-во попавших в фигуру выстрелов
n - общее кол-во выстрелов
	S(фиг) = S(квад) * m / n = 100 * m / n

В моделировании мы делаем то же самое - чтобы приблизиться к истине, получить объективные характеристики процесса, мы проводим **множество испытаний**. Каждый выстрел - испытание.

Выводы для любого имитационного эксперимента:
- каждый прогон можно рассматривать как 1 эксп на модели
- с **увеличением** продолжительности прогона (числа испытаний) отклонение измеряемой величины от ее реального значения уменьшается, т.к. наблюдаемая система переходит в стационарное состояние
- влияние переходных условий можно уменьшить, если увеличить кол-во экспериментов.
- есть предел, за которым увеличение продолжит прогона модели уже **не дает существ повышения точности**

**Переходные условия в имитационном эксперименте** — это начальный период работы модели, когда она «разгоняется» и переходит из одного состояния в другое, обычно из состояния с начальными условиями в стационарное (установившееся) состояние.

Для проведения статистического эксперимента необходимо ответить на **вопросы**:
- какова должна быть продолжительность прогона для достижения стационарных усл?
- как получить статистич независимые наблюдения? Это такие наблюдения (или результаты экспериментов, измерений), результат одного из которых никак не влияет на вероятность результатов остальных.

По результатам прогона расcчитывают **среднюю выборочную**, это приближение теоретического среднего распределения, основанное на выборке из него. Выборка - среднее - вывод о всем распределении

Виды планирования эксперимента:
- стратегическое планирование (что мы будем делать?)
>1) определить характер и взаимосвязи между характеристикой системы и ее откликами (выходными характеристиками) (влияет или нет. коэф корреляции)
>2) оптимизировать величину управляемых параметров, позволяющих получить максимум или минимум результирующих характеристик модели (корреляции)
- тактическое планирование (как мы будем этого достигать?)

Этапы планирования:
1. подготовка входных данных для каждого прогона
2. определение кол-ва прогонов
3. определение длительности каждого прогона
4. выявление длительности переходного процесса моделирования
5. разработка стратегий сбора данных для каждого прогона
6. методика оценки точности и чувствительности результатов моделирвания
7. планирование возможных сценариев развития системы, кот требуется оценить с помощью модели
8. оптимизация целевой функ

Имитационные эксперименты с моделью назыв **направленными вычисл экспериментами**. Типы:
1) отсеивающий несущественные факторы
2) оптимизирующий параметры системы
