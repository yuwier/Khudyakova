### Функции в моделировании систем

Виды функций:
- дискретная числовая (отдельные горизонтальные отрезки)
- непрерывная числовая (кусочно-непрерывная функция)
- табличная числовая
- дискретная атрибутивная
- табличная атрибутивная

В gpss можно двумя способами задать функции:
1. по умолчанию, например GENERATE, ADVANCE
2. при помощи оператора функции

В операторах по умолчанию значения внутри интервала распределены равномерно

```
<Метка> FUNCTION A,B
X1,Y1/X2,Y2/...XN,YN (координаты точек)
A - RNj (j=1,...7) или СЧА
B - Тип функций. Dn или Cn (D - число отрезков для дискретной, C - число точек)
```

```
Prihod FUNCTION RN3,D3
0.15,3/0.75,5/1,2
```

Равномерная функция на интервале от 3 до 7

```
Prihod FUNCTION RN2,C2
0,3/1,7
```

---

**Пример**

| интервал времени прихода | частота | суммарная частота |
| ------------------------ | ------- | ----------------- |
| 3                        | 0,15    | 0,15              |
| 5                        | 0,60    | 0,75              |
| 2                        | 0,25    | 1,00              |

```
Prihod FUNCTION RN3,D3
.15,3/.75,5/1,2
GENERATE FN$Prihod
QUEUE Ochered
SEIZE Prodavec
DEPART Ochered
ADVANCE 6,2
RELEASE Prodavec
TERMINATE 0

GENERATE 600
TERMINATE 1
START 1
```
