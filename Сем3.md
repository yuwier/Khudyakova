facility - устройство (блоки)
entries - колво транзактов вошедших в устройство
ut - коэф использования устройства. отношение времени рабты устройства ко времени работы системы

операторы перехода транзакта в блок отличный от последующего
несколько режимов:
1. BOTH - TRANSFER BOTH,B,C
BOTH - это оба, транзакт рассматривает оба устройства, метки блоков у которых указаны в операндах B, C и занимает тот блок, который свободен на данный момент. Метки блока - номер строки, чтобы туда послать транзакт (буквы и/или цифры). Метки перед операторами
.       GENERATE
Пример: условия такие же как в предыдущем, но в магазине работает два продавца
второй продавец быстрый, обслуживает за 3 +-1 минуты.

```
		GENERATE 4,2;
		QUEUE Och_prod;
		TRANSFER  BOTH,Pr_1,Pr_2;
Pr_1    SEIZE Prodavec_1;
        DEPART Och_prod;
		ADVANCE 5,3;
		RELEASE Prodavec_1;
		TERMINATE 0;
Pr_2    SEIZE Prodavec_2;
        DEPART Och_prod;
		ADVANCE 3,1;
		RELEASE Prodavec_2;
		TERMINATE 0;
		***
		GENERATE 600;
		TERMINATE 1;
		START 1;
```
